01 · Bối cảnh & Động lực
Sự tiến hóa của thuật toán ISD
1962 — Prange
Nền móng Information Set Decoding
Đưa ra khái niệm giải mã dựa trên tập thông tin sạch lỗi (p=0). Đơn giản nhưng xác suất thành công cực thấp khi mã dài.
1988 — Lee-Brickell
Duyệt lỗi cục bộ
Cho phép tối đa p lỗi trong tập thông tin. Tăng xác suất tìm thấy vector lỗi e lên gấp nhiều lần so với Prange.
1988 — Leon
Kỹ thuật Cửa sổ (Windowing)
Giới thiệu cửa sổ l bit để loại bỏ sớm các ứng viên không thỏa mãn hội chứng cục bộ, giảm đáng kể khối lượng tính toán.
1989 — Stern ★
Meet-in-the-Middle
Kết hợp Lee-Brickell + Leon + Birthday Paradox (va chạm bảng băm). Đây là thuật toán hiệu quả nhất tấn công SDP.
02 · Bài toán SDP
Syndrome Decoding Problem

ĐẦU VÀO (INPUT):

H ∈ 𝔽₂(n−k)×n # Ma trận kiểm tra (Parity-check)
s ∈ 𝔽₂n−k # Vector hội chứng (Syndrome)
w ∈ ℤ⁺ # Trọng số lỗi mục tiêu

MỤC TIÊU (OUTPUT):

Tìm vector lỗi bí mật e ∈ 𝔽₂ⁿ thỏa mãn đồng thời:

H · eᵀ = s và wt(e) = w
  • Độ khó NP-Hard: Được Berlekamp, McEliece chứng minh (1978).
  • Bùng nổ tổ hợp: Không gian duyệt lỗi lên tới C(n,w).
  • Ứng dụng PQC: Nền tảng an toàn của hệ mật hậu lượng tử McEliece.
03 · KIẾN TRÚC HỆ THỐNG
Thuật toán Stern (Mã giả)
STERN_ALGO: Input: H, s, w, p, l | Output: e Repeat: 1. $\Pi$ ← RandPerm(n) 2. H' ← H[:, $\Pi$], s' ← Gauss(H, s) 3. If Gauss_Fail: Continue 4. T ← Empty_Hash_Map() 5. (X, Y) ← Split(k, 2) // Pha X: Lưu trữ 6. For each $e_x \in \mathbb{F}_2^{k/2}$: 7. If wt($e_x$) == p: 8. $s_x$ ← $H'_{[0:l], X} \cdot e_x^T$, $T[s_x]$ ← $e_x$ // Pha Y: Đối soát 10. For each $e_y \in \mathbb{F}_2^{k/2}$: 11. If wt($e_y$) == p: 12. $s_y$ ← $H'_{[0:l], Y} \cdot e_y^T$ 13. $target$ ← $s'_{[0:l]} \oplus s_y$ 14. If $target \in T$: 15. $e$ ← [$T[target], e_y, 0, s' \oplus \dots$] 17. If wt(e) == w: Return $e \cdot \Pi^{-1}$ End Repeat
04 · Thuật toán Stern (Lý thuyết & Ví dụ)
Cơ chế Meet-in-the-middle & Hash Collision
01
Biến đổi Systematic Form
Hoán vị $\Pi$ và khử Gauss đưa $H$ về dạng $[H' | I_{n-k}]$ để cô lập tập thông tin.
02
Phân hoạch Splitting
Chia tập $k$ thành $X, Y$ ($k/2$ mỗi khối). Giả định có đúng $p$ lỗi mỗi khối.
03
Cửa sổ va chạm $l$ bit
Sử dụng $l$ hàng đầu làm màng lọc sơ bộ để giảm không gian tìm kiếm.
04
Bảng băm Pha X
Duyệt các tổ hợp trong $X$, tính hội chứng $l$ bit và lưu vào bảng băm (Key: Syndrome, Value: Index).
05
Va chạm & Xác thực
Tra cứu khối $Y$ trong bảng băm. Nếu khớp, kiểm tra điều kiện trọng số toàn cục $wt(e)=w$.
Las Vegas: Nếu thất bại ở bước 5, lặp lại từ Bước 1 với hoán vị $\Pi$ mới.
Ví dụ số minh họa (n=8, k=4, w=2, p=1, l=2) Target $s = [1, 1, 0, 1]^T$
1. Trạng thái ma trận $H_{std}$ & Pha X:
H = [ 1 0 1 0 | 1 0 0 0 ]
    [ 0 1 1 1 | 0 1 0 0 ] ← Win $l$
    [ 1 1 0 1 | 0 0 1 0 ]
    [ 0 1 0 1 | 0 0 0 1 ]
• X={c1, c2}: Lưu c1 $\to$ Key 10; c2 $\to$ Key 01
2. Pha Y & Va chạm:
• Mục tiêu cửa sổ: $s_l = [1, 1]^T$
• Xét c4 thuộc Y ($S_{y4} = [0, 1]^T$):
• Tính: $S_y \oplus s_l = [0, 1] \oplus [1, 1] = \mathbf{[1, 0]}$
→ Khớp Key 10 (của c1) trong bảng băm!
Kết quả: Lỗi nằm tại {c1, c4}.
Kiểm tra: $wt(1,0,0,1,...) = 2 = w$. (Xong)
05 · Xác suất lý thuyết & Độ phức tạp
Chiến lược tối ưu hóa Las Vegas
Xác suất thành công một vòng lặp ($P$)
$$\frac{\binom{k/2}{p}^2 \times \binom{n-k-l}{w-2p}}{\binom{n}{w}}$$
Số vòng lặp kỳ vọng: $\mathbb{E}[\text{it}] \approx 1/P$

Cơ chế đánh đổi (Trade-off)

• Tăng $p$: Giảm số vòng lặp đáng kể nhưng gây bùng nổ bộ nhớ RAM.
• Tăng $l$: Lọc nhiễu tốt hơn nhưng làm giảm xác suất thành công $P$.

Hiệu quả thực tế

Cải thiện độ phức tạp từ $O(2^k)$ (Brute-force) xuống $O(2^{k/2})$. Thuật toán luôn đảm bảo tìm ra lời giải chính xác 100% sau đủ số vòng lặp.
